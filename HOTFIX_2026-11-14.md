# DeltaTV — hotfix backend (14/11/2026)

## Problema confirmado
`client.admin.service.js` importava `MAX_CLIENTS_PER_PARTNER`, que deixou de ser exportado por `client.service.js`. Isso interrompe o processo Node ao carregar os módulos ES. O teste verifica que essa dependência não existe mais.

## SQL PostgreSQL 42601
O log enviado não identifica a query ou rota, portanto **a causa ainda não está confirmada**. O `errorHandler` foi aprimorado para registrar apenas `req.id`, método, padrão da rota, código PostgreSQL, posição de sintaxe e tipo SQL, sem instruções nem parâmetros. Use o próximo erro com a rota e a posição para localizar a query.

## HTTP 404 na origem HLS
A resposta 404 foi enviada pela origem `http://69.162.119.170`, cujo servidor responde como nginx. Confirme a URL de origem válida, expiração/autorização do token, playlists e segmentos. Não é prova de falha no Nginx da VPS DeltaTV.

## Como aplicar com segurança

1. Faça backup **antes** de extrair o hotfix e trabalhe no diretório do backend:

```bash
cd /var/www/backend-deltaTV
BACKUP_DIR="$HOME/backup-deltatv-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$BACKUP_DIR/src/modules/clients" "$BACKUP_DIR/src/shared"
cp -a src/modules/clients/client.admin.service.js "$BACKUP_DIR/src/modules/clients/"
cp -a src/shared/errors.js "$BACKUP_DIR/src/shared/"
```

2. Extraia o hotfix **na raiz `/var/www/backend-deltaTV`**, de modo que os arquivos sejam colocados em `src/modules/clients/` e `src/shared/`. Não substitua `.env` nem `package.json`.
3. Execute:

```bash
node --check src/modules/clients/client.admin.service.js
node --check src/shared/errors.js
node --test tests/regression/backend-hotfix.test.js
pm2 restart DeltaTV-Server --update-env  # ajuste o nome para o registrado no seu PM2
pm2 logs DeltaTV-Server --lines 70 --nostream
```

4. Acompanhe respostas da API e as próximas ocorrências `pgCode=42601`.

**Não execute migrações para aplicar este hotfix.** A alteração é pontual em JavaScript. Se o SQL 42601 persistir, envie a nova linha do erro (com rota e position) e o requestId associado; não envie credenciais ou URLs HLS completas.
